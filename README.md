# Fun

Маркетплейс модов для Claude Code.

## anime-companion: Claude-chan ✿

Аниме-компаньон для Claude Code. Пиксельная Claude-chan разыгрывает всё, что делает Claude: думает с облачком, листает книжку на `Read`, колдует палочкой на `Edit`/`Write`, стучит по ноутбуку на `Bash`, ищет с лупой, призывает клонов для агентов, пугается ошибок, празднует конец хода и засыпает, когда долго тихо.

![Все 13 состояний Claude-chan](docs/claude-chan-moods.png)

Что умеет:

- панель с анимированной сценой (в терминале около 8 кадров в секунду, на десктопе самоанимирующийся SVG);
- диалоговое окно в стиле визуальной новеллы с репликами и каомодзи;
- счётчики: комбо за ход и рекорд, уровень, ходы, действия, токены, счётчики по типам;
- журнал квестов: каждый вызов инструмента со статусом, вызовы субагентов с отступом;
- в чате: её реплика над каждым вызовом инструмента и живая сцена по команде `/claude-chan`;
- строка Claude-chan под каждым ответом: лицо, реплика, время хода, комбо и действия по типам;
- текстовая карточка по `/claude-chan`, строка статуса и всплывашки на 10, 25, 50 и 100 комбо;
- **Claude-chan Live**: страница-артефакт на claude.ai с анимированной Claude-chan, которую мод обновляет вживую. Её показывает любое приложение Claude, в том числе для облачных сессий.

### Где её видно

| Где запущен Claude Code | Что видно |
| --- | --- |
| Терминал (`claude`) | всё: панель с анимацией, сцена и реплики в чате, статус, всплывашки |
| Локальная сессия во вкладке Code десктопного приложения | панель и чат в SVG-версии (мод ставится из терминала в область user) |
| Облачная сессия в приложении Claude, с компьютера или телефона | страница Claude-chan Live с анимацией и карточка по `/claude-chan`. Окно облачной сессии само интерфейс модов не рисует |

### Установка

В терминальной сессии Claude Code:

```
/plugin install anime-companion --marketplace sodlele/fun
```

Ответьте `y` на «Add marketplace?», выберите область установки (по умолчанию user) и при желании задайте настройки.

### Использование

- `/claude-chan` рисует живую Claude-chan в чате, выводит текстовую карточку и открывает панель там, где клиент умеет панели. В конце видно, какие клиенты подключены и где панель реально показана.
- `/claude-chan close` закрывает панель.
- `/claude-chan live <адрес страницы>` подключает страницу Claude-chan Live, `/claude-chan live off` отключает.
- `/claude-chan test` отправляет пробную строку через каждый канал вывода, чтобы понять, что показывает ваш клиент.
- Сама панель открывается при старте, только если терминал шире 144 колонок; иначе вызывайте её командой.

Настройки:

| Поле | Значения | По умолчанию |
| --- | --- | --- |
| `language` | `ru`, `en` | `ru` |
| `autoOpen` | открывать панель при старте сессии | `true` |
| `chatLines` | реплика над каждым вызовом инструмента в чате | `true` |
| `turnCard` | строка Claude-chan под каждым ответом | `true` |
| `liveUrl` | адрес страницы Claude-chan Live | пусто |

### Claude-chan Live

Страница лежит в [`live/claude-chan-live.html`](live/claude-chan-live.html). Чтобы завести свою:

1. Попросите Claude опубликовать этот файл как артефакт с возможностью `db`.
2. В сессии с модом наберите `/claude-chan live <адрес артефакта>`.

Мод записывает состояние в документ `live/state` базы артефакта через инструмент ArtifactData, не чаще раза в 0,7 секунды. Страница подписана на этот документ и перерисовывает Claude-chan сама. Пока данных нет, она показывает демо всех состояний.
